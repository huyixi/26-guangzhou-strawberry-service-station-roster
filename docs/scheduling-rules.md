# 音乐节公平排班算法 MVP

## 1. 硬约束

1. 排班日期为演出日（`09-25`、`09-26`、`09-27`），值班窗口为每天 `12:00–21:30`；所有成员这三天均可参与排班。
2. 每天 `12:00–21:30` 任意时刻至少 4 人在岗。
3. 任意时刻至少 1 名男性在岗。
4. 任意个人单次连续值班不得超过 120 分钟。
5. 换班时允许最多约 3 分钟重叠，避免交接出现空档。

## 2. 排班优化目标

按以下优先级优化：

1. 三天总工时尽量公平。
2. 优先照顾当前观演满意度最低的人。
3. 尽量让所有人的满意度接近。
4. 单次值班原则上不少于 60 分钟，并尽量接近 75 分钟。
5. 收尾班尽量平均分配。
6. 尽量减少不必要的换班。
7. 在以上条件接近时，让全体获得的偏好分尽可能高。

## 3. 偏好计分

| 偏好 | 分数 | 最多计分 |
| --- | ---: | ---: |
| 必须看 | 100 | 3 场 |
| 特别想看 | 30 | 4 场 |
| 有点想看 | 10 | 2 场 |

填写超过计分上限的艺人仍然可以看，只是不再增加公平评分。

## 4. 个人满意度

```text
满意度 = 实际获得的偏好分 ÷ 个人全部计分名额对应的总分
```

例如某人有：

* 3 个“必须看”计分名额
* 4 个“特别想看”计分名额
* 1 个“有点想看”计分名额

则满分为：

```text
3×100 + 4×30 + 1×10 = 430
```

如果实际获得 300 分：

```text
满意度 = 300 ÷ 430 ≈ 69.8%
```

## 5. 什么算“看到了”

只有完整观看一场演出才计分。

要求：

```text
值班结束时间 ≤ 演出开始时间 - 5分钟
下一次值班开始时间 ≥ 演出结束时间 + 5分钟
```

不完整观看则该场不计偏好分。

## 核心原则

> 先保证岗位覆盖和工时公平，再优先补偿观演权益较少的人，最后才追求整体看更多演出。
